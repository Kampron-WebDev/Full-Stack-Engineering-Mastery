## 🧸 The big idea

A database is a super-organised library. Tables are shelves, rows are books, keys are catalogue numbers, and SQL is how you ask the librarian for exactly what you need.

## 🎯 By the end of this month you can…

- Model data with tables, keys, relationships and constraints.
- Normalise a schema and draw ER diagrams.
- Write SQL: CRUD, JOINs, GROUP BY, subqueries, CTEs and window functions.
- Explain transactions and ACID.

## 📚 What you will study

- **Theory:** Tables · Rows · Relationships · Primary keys · Foreign keys · Constraints · Transactions · Normalization
- **SQL:** SELECT · INSERT · UPDATE · DELETE · JOIN · GROUP BY · CTE · Subqueries · Window functions
