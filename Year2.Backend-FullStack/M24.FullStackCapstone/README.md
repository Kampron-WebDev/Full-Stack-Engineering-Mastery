## 🧠 The three layers of learning

| Layer | Question for this month |
|---|---|
| 1 · **Use it** | How do I build each feature? |
| 2 · **How it works** | How do all the parts interact at runtime? |
| 3 · **When to use it** | Is the architecture right for the business? |
