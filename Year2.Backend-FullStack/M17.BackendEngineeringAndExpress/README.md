## 🧸 The big idea

A backend is a well-run restaurant kitchen: the waiter (route) takes the order, the head chef (controller) delegates, cooks (services) do the work, and the storeroom keeper (repository) fetches ingredients. Everyone has one job.

## 🎯 By the end of this month you can…

- Design clean REST APIs.
- Structure a backend in layers: routes, controllers, services, repositories.
- Write middleware for validation, errors, logging and config.
- Explain dependency injection and why it helps testing.

## 📚 What you will study

- **API:** REST APIs · Routes · Controllers
- **Architecture:** Services · Repositories · Dependency injection concepts
- **Cross-cutting:** Middleware · Validation · Error handling · Logging · Configuration
