## 🧸 The big idea

Tests are safety nets under a trapeze. With good nets you can try bold moves (refactors, new features) without fear.

## 🎯 By the end of this month you can…

- Explain the testing pyramid and pick the right test type.
- Write unit tests with Vitest.
- Write integration and API tests against a real test database.
- Test React components the way users use them.
- Write reliable E2E tests with Playwright.

## 📚 What you will study

- **Strategy:** Testing pyramid · Test doubles · Coverage
- **Levels:** Unit testing · Integration testing · API testing · E2E testing
- **Tools:** Vitest/Jest · React Testing Library · Playwright

## 🗓️ Four-week plan

| Week | Theme | Focus |
|---|---|---|
| W1 | Unit Testing | Testing pyramid · Vitest · Mocks & fakes · TDD |
| W2 | Integration & API | Test databases · Supertest · Fixtures |
| W3 | Component Testing | React Testing Library · User-centric queries · Mocking fetch |
| W4 | E2E + Assignment | Playwright · Flaky tests · CI-ready suites |

Every week follows the same rhythm: **Days 1–5** lessons (10-part format) · **Day 6** project work · **Day 7** review + quiz.

## 🏗️ Month project: Serious Test Suite

Take a previous project and give it a professional automated test suite.

- [ ] Unit + integration + E2E
- [ ] Runs in one command
- [ ] Meaningful coverage report
- [ ] Zero flaky tests over 10 runs

## 🧠 The three layers of learning

| Layer | Question for this month |
|---|---|
| 1 · **Use it** | How do I write tests? |
| 2 · **How it works** | How do test runners, mocks and browsers automate checks? |
| 3 · **When to use it** | What should (and should not) be tested here? |
