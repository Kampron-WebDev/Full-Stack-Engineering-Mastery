## 🧸 The big idea

Next.js is React with a built-in server and a map of your whole site. Some of your components now run in the kitchen (server) and some at the table (browser).

## 🎯 By the end of this month you can…

- Build apps with the App Router, layouts and nested routes.
- Explain Server vs Client Components and choose correctly.
- Fetch data on the server and set metadata.
- Write route handlers and error/loading UI.

## 📚 What you will study

- **Routing:** App Router · Routing · Layouts
- **Components:** Server Components · Client Components
- **Data:** Data fetching · Metadata · Route handlers
- **Resilience:** Error boundaries · Loading UI
