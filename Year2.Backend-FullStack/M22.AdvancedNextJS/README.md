## 🧸 The big idea

Now you learn Next.js's memory (caching) and its shortcuts (server actions, streaming). Used well, they make apps fast. Used badly, they show stale data.

## 🎯 By the end of this month you can…

- Mutate data with Server Actions.
- Control caching and revalidation deliberately.
- Stream UI with Suspense.
- Add authentication and middleware.
- Use parallel and intercepting routes.

## 📚 What you will study

- **Mutations:** Server Actions
- **Caching:** Caching · Revalidation · Streaming · Suspense
- **Security:** Authentication · Middleware · Server/client boundaries
- **Advanced routing:** Parallel routes · Intercepting routes
