# Skeleton generator

`curriculum.mjs` is the source of truth for all 36 months (outcomes, topics, weeks, projects, layers).
`generate.mjs` turned it into the Year / Month / Exam READMEs and PROGRESS.md.

⚠️ Re-running `node tools/skeleton/generate.mjs` OVERWRITES those READMEs and PROGRESS.md
(including your scores!). Only use it on a fresh copy, or edit month READMEs by hand instead.
