## 🧸 The big idea

Almost every server in the world runs Linux. It is the ground your applications stand on, so you learn to live there comfortably.

## 🎯 By the end of this month you can…

- Navigate the filesystem and manage permissions, users and groups.
- Manage processes, signals and systemd services.
- Read logs and troubleshoot networking.
- Use SSH securely and write shell scripts.
- Deploy an app to a Linux server behind nginx.

## 📚 What you will study

- **System:** Filesystem · Permissions · Users · Processes · Services · Logs
- **Network:** SSH · Networking
- **Automation:** Shell scripting

## 🗓️ Four-week plan

| Week | Theme | Focus |
|---|---|---|

| W3 | Networking & SSH | ip/ss/dig/curl · SSH keys & config · Firewalls |
| W4 | Scripting + Project | Bash scripting · cron · Server deployment |

Every week follows the same rhythm: **Days 1–5** lessons (10-part format) · **Day 6** project work · **Day 7** review + quiz.
