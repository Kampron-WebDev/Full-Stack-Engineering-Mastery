## 🧸 The big idea

A large language model is an extremely well-read autocomplete. AI engineering is building reliable products around it: giving it the right context, tools and guardrails, and measuring whether it actually works.

## 🎯 By the end of this month you can…

- Explain LLMs, transformers, tokens and embeddings.
- Use structured output, tool calling and streaming.
- Build RAG with a vector database and reranking.
- Build agents with memory and guardrails.
- Evaluate and observe AI features in production.

## 📚 What you will study

- **Foundations:** LLMs · Transformers · Tokens · Embeddings
- **Building:** Prompt engineering · Structured output · Tool calling · Streaming
- **Retrieval:** Vector databases · RAG · Reranking
- **Systems:** Agents · Memory · Evaluation · Guardrails · AI observability
