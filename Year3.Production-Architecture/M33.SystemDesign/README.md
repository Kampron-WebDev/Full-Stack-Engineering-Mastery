## 🧸 The big idea

System design is drawing the blueprint for a huge building before anyone lays a brick: how many people will use it, where the lifts go, what happens in a fire.

## 🎯 By the end of this month you can…

- Use a repeatable framework: requirements, estimation, API, data, high-level and deep dive.
- Estimate capacity (QPS, storage, bandwidth).
- Combine caches, queues, load balancers, storage and CDNs.
- Design well-known systems and discuss failure modes.

## 📚 What you will study

- **Method:** Requirements · Capacity estimation · APIs · Data modeling
- **Building blocks:** Databases · Caches · Queues · Load balancers · Storage · CDNs
- **Case studies:** URL shortener · Chat application · YouTube · Uber · Netflix · E-commerce · Learning platform · Payment system
- **Reliability:** Failure modes

## 🧠 The three layers of learning

| Layer | Question for this month |
|---|---|
| 1 · **Use it** | What components exist? |
| 2 · **How it works** | How do they behave under load and failure? |
| 3 · **When to use it** | Which design is right for these requirements? |
