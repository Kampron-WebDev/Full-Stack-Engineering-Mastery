## 🧸 The big idea

CI/CD is a factory conveyor belt: every change is automatically checked, packaged and delivered, so shipping becomes boring and safe.

## 🎯 By the end of this month you can…

- Build CI pipelines with GitHub Actions.
- Automate tests, linting and builds with caching.
- Deliver to environments with secrets managed safely.
- Release, deploy and roll back safely.

## 📚 What you will study

- **CI:** Continuous integration · GitHub Actions · Automated tests
- **CD:** Continuous delivery · Deployment pipelines · Releases · Rollbacks
- **Safety:** Secrets management · Environments & approvals
