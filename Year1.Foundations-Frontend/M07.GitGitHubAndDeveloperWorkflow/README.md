## 🧸 The big idea

Git is a time machine plus a parallel universe machine for your code. GitHub is where teams meet to review each other's universes before joining them together.

## 🎯 By the end of this month you can…

- Explain how Git stores history (commits, trees, blobs, branches as pointers).
- Branch, merge, rebase and resolve conflicts calmly.
- Undo safely with reset, revert and stash.
- Run a professional pull-request workflow with reviews, issues and releases.
- Set up npm/pnpm, ESLint, Prettier and debugging for a project.

## 📚 What you will study

- **Git:** init · add · commit · branch · merge · rebase · reset · revert · stash · tags
- **GitHub:** Repositories · Pull requests · Code reviews · Issues · Projects · Releases
- **Tooling:** VS Code · npm · pnpm · package.json · ESLint · Prettier · Debugging · DevTools
