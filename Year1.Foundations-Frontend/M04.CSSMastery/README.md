## 🧸 The big idea

If HTML is the skeleton, CSS is the clothes and the furniture arrangement. The browser follows a strict rulebook (the cascade) to decide which clothes win. Learn the rulebook and CSS stops feeling random.

## 🎯 By the end of this month you can…

- Predict which CSS rule wins using the cascade, specificity and inheritance.
- Build any layout with Flexbox and Grid.
- Make responsive designs with media and container queries.
- Use custom properties, transitions and animations.
- Compare CSS architectures (BEM, utility-first, CSS Modules, Tailwind) and choose one.

## 📚 What you will study

- **Rules:** Cascade · Specificity · Inheritance · Box model · Units · Colors · Typography
- **Layout:** Positioning · Flexbox · CSS Grid
- **Adaptive:** Responsive CSS · Media queries · Container queries · Custom properties
- **Motion:** Transitions · Animations
- **Architecture:** BEM · Utility CSS · Component CSS · CSS Modules · Tailwind concepts
