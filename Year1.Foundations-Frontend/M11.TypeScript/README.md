## 🧸 The big idea

TypeScript is spell-check for your program's shapes. It catches "you promised a number but gave a string" before your users ever see it.

## 🎯 By the end of this month you can…

- Type objects, functions and modules with interfaces and aliases.
- Use unions, narrowing, type guards and discriminated unions to model states.
- Write reusable generic functions and types.
- Use utility, conditional and mapped types.
- Migrate a JavaScript project to strict TypeScript.

## 📚 What you will study

- **Basics:** Primitive types · Objects · Interfaces · Type aliases · tsconfig
- **Modelling:** Union types · Narrowing · Type guards · Discriminated unions
- **Reuse:** Generics · Utility types
- **Advanced:** Conditional types · Mapped types
