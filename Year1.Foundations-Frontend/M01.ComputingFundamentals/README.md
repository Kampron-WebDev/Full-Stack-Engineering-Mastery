## 🧸 The big idea

A computer is a very fast, very obedient kitchen. The CPU is the chef, RAM is the kitchen counter, storage is the pantry, and a program is the recipe. This month you learn how the kitchen works, how to talk to it through the terminal, and how to write recipes that are fast (algorithms) and well organised (data structures).

## 🎯 By the end of this month you can…

- Explain what happens inside a computer when a program runs (CPU, RAM, storage, OS, processes, threads).
- Convert numbers between decimal, binary and hexadecimal, and explain how text and decimals are stored.
- Explain the difference between a compiler, an interpreter and a runtime like Node.js.
- Use the terminal confidently and write small JavaScript programs with Node.js.
- Describe Big-O and pick a sensible data structure (array, linked list, stack, queue, hash map, tree, graph) for a problem.
- Build a CLI application with no framework: the Student Record Management System.

## 📚 What you will study

- **Hardware & OS:** CPU · RAM · Storage · Operating systems · Processes · Threads · Filesystems
- **Data:** Binary · Hexadecimal · Data representation (integers, text, floats)
- **Running code:** Compilers · Interpreters · Runtime environments · Terminal · Command line (Windows + Linux)
- **Computer science:** Algorithms · Big-O · Arrays · Linked lists · Stacks · Queues · Hash maps · Trees · Graphs · Recursion

## 🏗️ Month project: Student Record Management System (CLI)

A command-line program with no framework that stores students, courses and grades in a JSON file. The point is logic and data structures, not pretty screens.

- [ ] Add / edit / delete / list students
- [ ] Record grades per course and compute averages
- [ ] Search by name (hash map) and sort by grade (your own sort)
- [ ] Undo the last action (stack)
- [ ] Save and load from a JSON file
- [ ] Automated tests for the core logic

## 🧠 The three layers of learning

| Layer | Question for this month |
|---|---|
| 1 · **Use it** | How do I use the terminal, Node and basic data structures? |
| 2 · **How it works** | What is the CPU/OS/runtime actually doing when my code runs? |
| 3 · **When to use it** | Which data structure fits this problem, and what does it cost in time and memory? |
