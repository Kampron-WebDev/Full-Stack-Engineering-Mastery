## 🧸 The big idea

A good building has ramps, not just stairs. Accessibility means everyone can use your app: keyboard users, screen-reader users, people on tiny phones or slow connections.

## 🎯 By the end of this month you can…

- Apply WCAG principles (POUR) to real interfaces.
- Make everything keyboard-usable with correct focus management.
- Use ARIA only when HTML is not enough, and use it correctly.
- Build mobile-first fluid layouts with responsive typography and images.
- Audit a site with screen readers and automated tools.

## 📚 What you will study

- **Accessibility:** WCAG · Keyboard navigation · Screen readers · Focus management · ARIA · Accessible forms · Semantic HTML
- **Responsive:** Mobile first · Fluid layouts · Responsive typography · Images · Breakpoints · Adaptive interfaces
