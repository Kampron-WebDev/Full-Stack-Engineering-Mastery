## 🧸 The big idea

React lets you build a UI from LEGO bricks (components). You describe what the screen should look like for the current data, and React works out what to change.

## 🎯 By the end of this month you can…

- Build UIs from components, props and state.
- Handle events, forms, lists and conditional rendering.
- Use hooks (useState, useEffect and friends) correctly.
- Compose components and add routing.
- Deliver the Year 1 capstone with tests, accessibility and API integration.

## 📚 What you will study

- **Core:** JSX · Components · Props · State · Events
- **Patterns:** Forms · Hooks · Lists · Conditional rendering · Component composition
- **Apps:** Routing · Testing basics
