## 🧸 The big idea

JavaScript is the brain you add to the web page. This month you learn to think in JavaScript without leaning on AI: small daily katas until the basics are automatic.

## 🎯 By the end of this month you can…

- Write JavaScript fluently: types, operators, conditions, loops, functions.
- Use arrays, objects and strings with their core methods.
- Explain scope and closures with your own examples.
- Use higher-order functions (map, filter, reduce) naturally.
- Split code into ES modules.

## 📚 What you will study

- **Basics:** Variables · Types · Operators · Conditions · Loops
- **Functions:** Functions · Scope · Closures · Higher-order functions
- **Data:** Arrays · Array methods · Objects · Strings
- **Organisation:** Modules

## 🗓️ Four-week plan

| Week | Theme | Focus |
|---|---|---|
| W1 | Values & Control Flow | let/const · Types & coercion · Operators · Conditions · Loops |
| W2 | Functions & Scope | Function forms · Parameters & defaults · Scope · Closures |
| W3 | Arrays, Objects, Strings | Array methods · Objects & destructuring · Spread/rest · String methods |
| W4 | Higher-Order Functions, Modules + Project | map/filter/reduce · Composing functions · ES modules · Finance tracker |

Every week follows the same rhythm: **Days 1–5** lessons (10-part format) · **Day 6** project work · **Day 7** review + quiz.
