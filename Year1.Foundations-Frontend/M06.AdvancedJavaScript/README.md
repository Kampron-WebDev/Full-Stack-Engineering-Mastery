## 🧸 The big idea

JavaScript has one chef (one thread) who never waits around. The event loop is the chef's to-do list. Once you understand that list, promises, async/await and the DOM stop being magic.

## 🎯 By the end of this month you can…

- Explain execution context, the call stack and hoisting.
- Explain prototypes, classes and the four rules of "this".
- Explain the event loop, macrotasks and microtasks, and predict output order.
- Write robust async code with promises, async/await and error handling.
- Build interactive interfaces with the DOM and events.

## 📚 What you will study

- **Engine:** Execution context · Call stack · Hoisting · Closures
- **Objects:** Prototypes · this · Classes · OOP · Functional programming
- **Async:** Event loop · Microtasks · Promises · Async/await · Error handling
- **Browser:** Browser APIs · DOM · Events
