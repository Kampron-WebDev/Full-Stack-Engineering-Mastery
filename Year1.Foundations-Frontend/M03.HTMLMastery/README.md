## 🧸 The big idea

HTML is the skeleton of a web page. It says what each thing IS (a heading, a button, a form), not what it looks like. A good skeleton helps browsers, search engines and screen readers understand your page.

## 🎯 By the end of this month you can…

- Write valid, semantic HTML documents from memory.
- Build accessible forms with native validation.
- Use tables, images and multimedia correctly.
- Add metadata for SEO and social sharing.
- Explain why semantic HTML is the foundation of accessibility.

## 📚 What you will study

- **Structure:** Document structure · Semantic HTML · Metadata · SEO
- **Content:** Text · Links · Images · Multimedia · Tables
- **Interaction:** Forms · Form validation
- **Access:** Accessibility foundations
