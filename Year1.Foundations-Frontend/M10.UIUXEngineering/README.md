## 🧸 The big idea

Good design is like a good signpost: people know where to go without thinking. You learn to design before you code, so code is solving the right problem.

## 🎯 By the end of this month you can…

- Apply typography, color, spacing and hierarchy deliberately.
- Map user journeys and flows, then wireframe them.
- Build a small design system with tokens and components.
- Design empty, error and loading states on purpose.
- Prototype in Figma before writing code.

## 📚 What you will study

- **Visual:** Typography · Color theory · Layout · Visual hierarchy · Spacing
- **Experience:** User journeys · User flows · Wireframes · Prototypes · Cognitive load
- **Systems:** Design systems · Empty states · Error states · Loading states · Figma

## 🧠 The three layers of learning

| Layer | Question for this month |
|---|---|
| 1 · **Use it** | How do I make interfaces look right? |
| 2 · **How it works** | Why do users perceive layouts the way they do? |
| 3 · **When to use it** | When is a design system worth its cost? |
